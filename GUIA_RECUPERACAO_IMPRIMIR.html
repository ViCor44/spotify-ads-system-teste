1. Confirmar o backup diário

No computador onde o sistema está atualmente instalado:

  1. Abra a pasta C:\xampp\htdocs\spotify-ads-system-teste.
  2. Execute instalar_backup_diario.bat com duplo clique.
  3. Confirme que aparece a mensagem “Tarefa criada”.
  4. Abra C:\BackupMySQL e confirme que existem ficheiros com este formato:
spot-master-backup-AAAAMMDD-HHMMSS.zip

A tarefa corre diariamente às 23:00 e conserva os 5 backups mais recentes. Se o computador estiver indisponível nessa hora, a tarefa arranca quando voltar a estar disponível.

Criar um backup imediatamente

Execute criar_backup_agora.bat com duplo clique. Esta opção funciona mesmo quando o Windows bloqueia a execução direta de ficheiros PowerShell.

criar_backup_agora.bat

Confirmar a cópia no Google Drive

  • O Google Drive para computador está instalado e iniciado.
  • A pasta C:\BackupMySQL está configurada para sincronização.
  • O ZIP mais recente aparece também em drive.google.com.
  • A conta Google tem autenticação de dois fatores ativa.
Um ficheiro existente apenas em C:\BackupMySQL não fica protegido contra avaria do disco. É obrigatório confirmar que foi enviado para o Google Drive.

Recuperação num PC novo

Executar estes passos pela ordem indicada

2. Após avaria do computador

  1. Instale XAMPP, Git e Composer.
  2. No painel do XAMPP, inicie Apache e MySQL.
  3. Abra o PowerShell e descarregue o programa:
cd C:\xampp\htdocs
git clone https://github.com/ViCor44/spotify-ads-system-teste.git
cd spotify-ads-system-teste
  1. Entre em drive.google.com e descarregue o ZIP mais recente para o novo computador.
  2. Restaure o sistema, substituindo o caminho abaixo pelo caminho real do ZIP:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\restore-system.ps1" -BackupFile "C:\Users\UTILIZADOR\Downloads\spot-master-backup-AAAAMMDD-HHMMSS.zip"
  1. Volte a instalar as duas tarefas automáticas:
.\instalar_robot.bat
.\instalar_backup_diario.bat
  1. Execute o diagnóstico:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\setup-new-pc.ps1" -CheckOnly
  1. Abra no navegador:
http://127.0.0.1/spotify-ads-system-teste/public/
  • Os anúncios aparecem e reproduzem corretamente.
  • Os horários aparecem no painel.
  • O Spotify está ligado; autorize novamente se for solicitado.
  • O painel indica que o robô está ativo após alguns minutos.
  • Foi criado um novo ZIP em C:\BackupMySQL.
  • O Google Drive está a sincronizar a pasta no novo computador.
